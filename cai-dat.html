Kho Drive và cấu hình dùng chung cho hệ thống.

Kết nối máy chủ

Địa chỉ Apps Script được đặt trong chung/cau-hinh.js, mục API_URL. Kho Drive thuộc máy chủ này. Chủ kho cài API AI ngay bên dưới; key được giữ ở máy chủ.

Cài đặt API AI

Chọn AI dùng chung cho quét hình và vẽ theo đề. Lưu Base URL, model và key của từng hãng trước khi kiểm tra kết nối.

Danh sách tra ngày 01/10/2026. Có thể lấy model từ tài khoản API hoặc nhập model khác. Chỉ chủ kho được thay đổi cấu hình; API key không được trả về trình duyệt sau khi lưu.

Macro dùng chung

Macro dùng khi build; mỗi file .tex vẫn chỉ chứa mã hình. Bản trực tuyến chỉ quản trị viên được sửa macro chung.
